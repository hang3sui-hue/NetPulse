# NetPulse

NetPulse is a Windows desktop network diagnostic tool built with Python and Tkinter.

Author: Hang3sui

## Features

- Automatic router and DNS detection
- Custom website and target ping testing
- Packet loss, latency, and jitter analysis
- Independent progress display for each target
- Ping by count or by time
- Custom ping interval
- Chinese and English UI
- TXT report export
- CSV data export
- Local history saving
- Custom target history
- Completion summary popup

## How to Run

```bash
python main.py
